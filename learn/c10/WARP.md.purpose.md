# C10 WARP.md 主要功能

## 核心职能
C10 是 PyTorch 的核心张量库，提供张量、设备、分发和内存管理的基础抽象。它被设计为最小依赖的基础库，供其他 PyTorch 组件构建。

## 关键内容

### 构建与测试
- CMake 构建系统（最低版本 3.18）
- 标准编译、测试运行和静态分析命令
- 测试位于 `test/` 目录，遵循 `c10_<test_name>` 命名模式

### 核心分发系统
- **DispatchKey**: 识别分发层级（后端、功能特性）
- **DispatchKeySet**: 64 位位集表示张量的活跃分发键
- **BackendComponent**: 支持 CPU、CUDA、XLA、MPS、IPU、XPU、HPU、VE、MTIA 等后端
- **功能键**: 每个后端可定制的特性（Dense、Sparse、Quantized 等）

### 张量实现 (TensorImpl)
- 存储管理和内存布局
- 大小、步长和形状信息
- 设备和数据类型跟踪
- 分发键管理
- 线程安全的写时复制存储支持

### 内存管理
- `Storage` 抽象提供底层数据分配
- `Allocator` 接口支持自定义内存分配策略
- 设备特定分配器处理后端内存管理
- 写时复制存储支持高效的延迟复制

### 工具组件
- `util/`: 通用 C++ 实用工具
- `core/impl/`: 内部实现（无向后兼容保证）
- `macros/`: 构建配置和编译器特定宏
- `mobile/`: 移动特定优化

## 开发指南要点

- **最小依赖**: C10 必须保持最小依赖，任何新依赖影响整个 PyTorch
- **线程安全**: 写时复制系统需要读写锁同步
- **性能**: C10 是性能关键库，最小化虚函数调用
- **新后端**: 更新 `BackendComponent` 枚举和相关分发键范围
- **测试**: 所有新功能需完整单元测试，使用 GoogleTest 框架
