# Copy-on-Write (CoW) 存储设计

## 核心功能
Copy-on-Write 库为 PyTorch 张量添加了惰性复制支持。设计保持了 PyTorch 的不变量：张量共享存储当且仅当它们实际别名（alias）。惰性复制的张量具有不同的存储，但共享同一个数据分配。

## 线程安全机制

### 关键设计原理
- 惰性克隆（lazy-clone）在逻辑上是**读操作**
- 物化（materialization）在逻辑上是**写操作**
- 共享存储的张量集合中，物化与其他读操作（包括惰性克隆）不能并发

### 竞态条件处理
- 不同存储但共享 CoW 上下文的张量可能发生物化与惰性克隆或其他物化的竞态
- 前提条件：上下文至少有两个引用，保证上下文不会突然消失
- 只需原子性引用计数增量即可

### 优化：最后一个副本窃取数据
- 问题：所有惰性复制并发物化时，需要确保都能并发读取数据
- 解决方案：
  - 复制数据时持有**共享锁**（shared lock）
  - 窃取数据时持有**独占锁**（exclusive lock）
  - 独占锁保证所有待处理的共享锁都已完成

## 主要概念总结

- **惰性复制**：创建张量时不立即复制数据，共享原始数据
- **物化**：首次写入时执行实际的数据复制或窃取
- **共享锁/独占锁机制**：确保并发安全性，防止数据竞态
