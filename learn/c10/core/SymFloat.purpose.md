## SymFloat 文件分析

**SymFloat** 是 PyTorch 的符号浮点数类，用于支持动态形状和符号计算。

### 核心设计

SymFloat 包含两个主要字段：
- `data_`：存储具体的浮点值（double）
- `ptr_`：指向 SymNode 的指针，当值是符号时使用

### 主要功能

**状态检查：**
- `is_symbolic()`：判断是否为符号值
- `as_float_unchecked()`：获取具体浮点值（仅在非符号时使用）
- `has_hint()`：检查是否有具体值提示

**数值运算：**
- 算术操作：`+`、`-`、`*`、`/`
- 比较操作：`sym_eq()`、`sym_ne()`、`sym_lt()`、`sym_le()`、`sym_gt()`、`sym_ge()`
- 特殊函数：`min()`、`max()`、`sqrt()`

**值转换：**
- `toSymNodeImpl()`：将符号浮点数转换为 SymNode
- `wrap_node()`：使用基础 SymNode 包装浮点值
- `guard_float()`：插入守卫以获取具体值

**规范化处理：**
- `normalize_symfloats()` 函数：统一处理符号值和非符号值的混合运算
  - 如果两个值都非符号，直接进行具体计算
  - 如果涉及符号值，将非符号值包装为 SymNode 后进行符号计算

### 关键特性

- **混合运算支持**：符号值和非符号值可以混合运算
- **延迟计算**：符号运算不立即求值，而是构建计算图
- **守卫机制**：`guard_float()` 用于在特定位置将符号值固化为具体值
- **输出流支持**：重载 `operator<<` 用于调试和日志输出

### 快速总结

- 符号浮点数包装类，支持混合符号/非符号运算
- 提供算术、比较、特殊函数等操作
- 通过 SymNode 实现符号计算图
- 包含守卫和提示机制用于值具体化
