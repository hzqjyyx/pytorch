## c10/util/Array.h 功能分析

这个文件定义了一个辅助模板函数 `array_of`，用于在编译时创建 `std::array` 对象。

**核心功能：**

- **简化 std::array 创建**：无需显式指定数组长度，通过可变参数模板自动推导
- **编译时计算**：使用 `constexpr` 关键字，确保在编译期间完成所有操作
- **完美转发**：利用 `std::forward<T>(t)...` 保留参数的值类别（左值/右值），避免不必要的拷贝
- **类型安全**：所有元素必须可转换为模板参数 `V` 指定的类型

**使用示例：**
```cpp
auto arr = c10::array_of<int>(1, 2, 3, 4);  // 创建 std::array<int, 4>
```

**设计目的：**
- 减少代码冗余性（无需写 `std::array<int, 4>{...}`）
- 提供更简洁的 API
- 在编译时验证类型和长度

**关键特性：**

- 模板参数 `V`：目标数组元素类型
- 模板参数 `T...`：可变参数包，允许任意数量的输入值
- 返回类型：`std::array<V, sizeof...(T)>` 自动推导长度
