## ScopeExit.h 文件分析

这个文件实现了 **RAII（Resource Acquisition Is Initialization）** 模式中的作用域退出机制，用于确保在代码块退出时自动执行清理函数。

### 核心组件

**scope_exit 类模板**
- 模板参数：`Callable` - 任何可调用对象（函数指针、lambda、函数对象等）
- 核心机制：在析构时自动调用保存的可调用对象
- 防止意外复制：删除拷贝构造和赋值运算符
- 支持移动语义：允许移动构造，移动后原对象进入"已释放"状态

**关键成员**
- `ExitFunction`：保存传入的可调用对象
- `Engaged`：标志位，控制析构时是否执行函数（支持通过 `release()` 显式禁用）

**make_scope_exit 辅助函数**
- 简化使用：自动推导可调用对象的类型
- 返回类型使用 `std::decay_t` 移除引用和 const 修饰符

### 设计特点

- **基于 LLVM 实现**：注释指向 LLVM 官方代码
- **符合 C++ 标准**：遵循 P0052R2 提案规范
- **类型安全**：完全通过模板编译期处理，零运行时开销
- **使用场景**：资源清理、异常安全保证、日志记录等

### 使用方式

```cpp
auto guard = c10::make_scope_exit([] { /* 清理代码 */ });
// 作用域退出时自动执行 lambda
```

### 特性总结

- **自动执行清理逻辑** - 作用域退出时
- **异常安全** - 即使异常抛出也能保证执行
- **可选禁用** - 通过 `release()` 取消自动执行
- **零成本抽象** - 编译期展开，无额外运行时开销
