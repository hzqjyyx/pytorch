这个文件实现了 **8 位浮点数到 32 位浮点数的转换**，支持两种 8 位格式：
- **E4M3FNUZ**（4 位指数，3 位尾数）
- **E5M2FNUZ**（5 位指数，2 位尾数）

**转换逻辑流程：**

1. **特殊值处理**
   - `x == 0` → 返回 0
   - `x == 0x80` → 返回 NaN

2. **提取位字段**
   - 从 8 位数据中分离尾数（低 wm 位）和指数（中间位）

3. **非规范化数处理**
   - 当指数为 0 时（subnormal number），执行重新规范化
   - 使用 CLZ（计数前导零）指令找到第一个 1 的位置
   - 调整尾数和指数以恢复正确的值

4. **指数偏移调整**
   - 计算 8 位和 32 位格式间的指数偏差
   - 应用偏移到转换后的指数

5. **尾数扩展**
   - 左移尾数以适应 32 位格式的 23 位尾数宽度

6. **重组 FP32**
   - 合并符号位（第 7 位）+ 调整后的指数 + 扩展的尾数
   - 返回最终的 32 位浮点数

**主要特点：**

- 支持多平台（CUDA、HIP、SYCL、MSVC、GCC）通过条件编译选择 CLZ 实现
- 处理有符号零和 NaN
- 正确处理非规范化数的舍入

**关键功能：**

- `fp8_fnuz_to_fp32_value<we, wm>(uint8_t x)` - 主转换函数，模板参数指定 8 位格式的指数和尾数宽度
