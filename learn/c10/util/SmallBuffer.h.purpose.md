**SmallBuffer** 是一个轻量级的固定大小数组分配器，实现了小对象优化（SBO）模式。

**核心功能：**

- **模板类**：`SmallBuffer<T, N>` 其中 T 是数据类型，N 是栈上缓冲区大小
- **混合存储策略**：
  - 当请求的大小 ≤ N 时，使用栈上的 `std::array<T, N>`
  - 当请求的大小 > N 时，动态分配堆内存
- **受限设计**（故意简化以提高性能）：
  - 仅支持 POD（Plain Old Data）类型
  - 不支持零初始化、调整大小、拷贝或非平凡类型
  - 支持移动语义（供函数返回值使用）

**主要方法：**

- `data()`、`operator[]`：访问缓冲区数据
- `size()`：返回当前大小
- `begin()`、`end()`：迭代器支持
- 析构函数自动释放堆分配的内存

**使用场景：**

- 为临时固定大小数组分配提供高效的内存管理
- 避免小尺寸分配时的堆开销
