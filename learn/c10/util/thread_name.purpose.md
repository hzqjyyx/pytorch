## 线程名称管理功能

这两个文件实现了 C10 库中的线程名称设置和获取功能。

**工作原理：**

头文件 (`thread_name.h`) 定义了两个公共 API 接口，导出给其他模块使用：
- `setThreadName(std::string name)` - 设置当前线程的名称
- `getThreadName()` - 获取当前线程的名称

实现文件 (`thread_name.cpp`) 通过条件编译来适配不同平台：

1. **平台检测**（第 6-13 行）：检查是否在 Linux（使用 glibc 2.12+）环境下，定义 `C10_HAS_PTHREAD_SETNAME_NP` 宏，排除 macOS 和 Android

2. **名称长度限制**（第 24 行）：pthread 的线程名称限制为 16 字节（包括空终止符），因此最大有效名称长度为 15 字符

3. **setThreadName 实现**（第 28-34 行）：
   - 将输入字符串截断到最大长度
   - 调用 `pthread_setname_np()` 设置线程名称
   - 在不支持的平台上该函数为空操作

4. **getThreadName 实现**（第 36-44 行）：
   - 创建大小为 16 的字符数组作为缓冲区
   - 调用 `pthread_getname_np()` 读取当前线程名称
   - 不支持的平台返回空字符串

**关键特性：**

- **跨平台兼容性**：通过条件编译支持不同操作系统
- **安全性**：自动处理名称长度限制，防止缓冲区溢出
- **线程安全**：调用 pthread 原生 API 操作当前线程

**主要功能列表：**

- 为 PyTorch 线程设置可读的名称，便于调试和监控
- 检索当前线程的名称信息
- 在仅支持 glibc 的 Linux 系统上启用此功能
- 自动处理平台差异和名称长度约束
