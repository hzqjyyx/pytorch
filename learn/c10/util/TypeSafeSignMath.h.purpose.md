## TypeSafeSignMath.h 功能分析

这个头文件提供了一套类型安全的符号和范围检查工具，用于处理有符号/无符号整数和自定义数值类型的比较问题。

### 核心函数：

- **is_negative(x)** - 检查数值是否为负
  - 无符号类型：总是返回 false
  - 有符号类型：返回 `x < 0`
  - 使用 SFINAE 根据类型特征自动分派

- **signum(x)** - 返回数值的符号
  - 无符号类型：返回 0 或 1
  - 有符号类型：返回 -1、0 或 1
  - 实现：`(0 < x) - (x < 0)`

- **signs_differ(a, b)** - 检查两个数值的符号是否不同
  - 组合使用 `is_negative()` 比较符号

- **greater_than_max(x)** - 检查数值是否超过目标类型的最大值
  - 通过比较 `numeric_limits::digits` 判断是否可能溢出
  - 避免不必要的比较警告

- **less_than_lowest(x)** - 检查数值是否小于目标类型的最小值
  - 4 个重载版本处理所有有符号/无符号组合
  - 避免无效的负数比较

### 设计特点：

• 使用 `std::true_type`/`std::false_type` 标签进行编译期类型分派

• 所有函数 `constexpr` - 支持编译期计算

• 处理有符号与无符号混合比较的类型安全性问题

• 包含 GCC/Clang 诊断抑制，避免虚假警告

• 文档注明对 `c10::Half` 等无 constexpr 构造函数的自定义类型的限制
