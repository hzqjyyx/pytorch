# c10/util/int128 文件分析

## 主要功能

这两个文件实现了一个 128 位无符号整数类型 `uint128`，基于 Google Protocol Buffers 的实现。由于 C++ 标准在很长时间内没有原生的 128 位整数支持，PyTorch 需要自己实现这个类型用于需要大整数计算的场景。

## 核心实现

### 数据结构 (c10/util/int128.h:106-107)

```cpp
uint64_t lo_;  // 低 64 位
uint64_t hi_;  // 高 64 位
```

采用小端序优化的字段顺序，使用两个 64 位整数表示一个 128 位整数。

### 关键运算实现

**1. 加法运算** (c10/util/int128.h:336-343)
- 分别相加高位和低位
- 检测低位加法的溢出（通过比较结果是否小于原值）
- 如果低位溢出，高位进位

**2. 减法运算** (c10/util/int128.h:345-351)
- 分别相减高位和低位
- 检测是否需要借位（被减数低位小于减数低位）
- 如果需要借位，高位减 1

**3. 乘法运算** (c10/util/int128.h:353-374)
- 将 128 位数拆分成 4 个 32 位段：a96, a64, a32, a00
- 使用类似竖式乘法的方式计算各段乘积
- 忽略超过 128 位的高位结果
- 逐项相加以捕获进位

**4. 除法和取模** (c10/util/int128.cpp:80-110)
- 使用长除法算法实现 `DivModImpl`
- 通过 `Fls128` 找到最高有效位位置
- 从最高位开始逐位试除
- 同时返回商和余数

**5. 移位运算** (c10/util/int128.h:244-314)
- 左移/右移分三种情况：
  - 移位量 < 64：需要在高低位之间传递位
  - 移位量 64-127：一个部分移到另一个部分
  - 移位量 >= 128：结果为 0

### 辅助功能

**位操作辅助函数** (c10/util/int128.cpp:58-78)
- `Fls64`: 找到 64 位数的最高有效位（Find Last Set bit）
- `Fls128`: 找到 128 位数的最高有效位
- 使用宏 `STEP` 实现二分查找优化

**流输出** (c10/util/int128.cpp:127-185)
- 支持十进制、十六进制、八进制输出
- 将 128 位数分成 3 段，每段小于 2^64
- 使用 64 位除法将各段转换为字符串
- 处理格式化选项（填充、对齐、进制前缀等）

### POD 结构体 (c10/util/int128.h:118-126)

```cpp
struct uint128_pod {
  uint64_t hi;
  uint64_t lo;
};
```

用于静态变量初始化，字段顺序与构造函数参数一致（与 `uint128` 类相反），便于直接初始化如 `kuint128max`。

## 设计特点

1. **平台无关性**：不依赖编译器特定的 128 位扩展
2. **性能优化**：小端序字段顺序、内联函数、constexpr 支持
3. **类型安全**：删除浮点和小整数的隐式转换构造函数
4. **运算符完整性**：支持所有标准算术、位运算、比较运算符

## 实际用途

- 需要精确表示大整数的数学计算
- 避免浮点数精度损失的场景
- 某些张量操作中的索引或大小计算
