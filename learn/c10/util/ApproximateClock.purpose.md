## ApproximateClock 文件功能分析

**ApproximateClock.h** 定义了一个时钟转换系统，用于将快速近似时间（如 TSC/RDTSC）转换为精确的 Unix 时间戳。

**核心概念：**

- `getApproximateTime()` 在 x86/x64 架构上使用 RDTSC 指令读取 CPU 时钟计数，其他平台降级到系统时间。RDTSC 非常快但单位不是纳秒。
- `getTime()` 获取精确的 Unix 纳秒级时间戳，在 Linux 上使用 `clock_gettime()` 以获得最佳性能。
- `ApproximateClockToUnixTimeConverter` 类在初始化和运行时各测量一次，通过计算两个时间点之间的关系建立近似时钟到 Unix 时间的映射。

**ApproximateClock.cpp** 实现了转换逻辑：

1. **measurePair()** - 在精确时间前后各读取一次近似时间，计算中间值作为该时刻的近似时间，避免单向偏差。

2. **measurePairs()** - 进行 5 次预热后采集 1001 次时间对，用于统计分析。

3. **makeConverter()** - 关键算法：
   - 计算 1001 个样本中每个的缩放因子（真实纳秒数 / 近似时钟滴答数）
   - 取中位数作为最终缩放因子（鲁棒性）
   - 通过 t0 偏移量校准，在双精度浮点的精度范围内优化数值稳定性
   - 返回一个闭包函数，将近似时间转换为 Unix 纳秒时间戳

**使用场景：**

在性能分析中，避免频繁调用昂贵的系统时钟，改用快速 RDTSC，之后离线转换为真实时间。

---

**核心要点：**

- **目标** - 提供低开销的时间计数，离线转换为精确的 Unix 纳秒时间戳
- **快速路径** - x86 使用 RDTSC，其他平台使用系统时钟
- **初始化** - 记录 1001 对时间样本（近似 + 精确）
- **转换算法** - 计算缩放因子和偏移量，使用闭包返回转换函数
- **数值稳定性** - 中位数选择、偏移量校准、相对计算而非绝对计算
- **精度** - 依赖 RDTSC 稳定性和初始校准质量，时间越长偏差可能累积
