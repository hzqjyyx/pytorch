## NetworkFlow.h 和 NetworkFlow.cpp 文件功能分析

这两个文件实现了一个**最小割（Min-Cut）/ 最大流（Max-Flow）算法**，用于网络流图的计算。

### 核心数据结构

**NetworkFlowGraph** (公共接口):
- 存储有向图的边集合，每条边包含源点、目标点和容量
- 提供 `add_edge()` 方法添加边
- 提供 `minimum_cut()` 方法计算最小割

**DinicFlowGraph** (内部实现):
- 使用 Dinic 算法实现最大流计算
- 图表示为邻接表，每条边都有反向边（用于残差图）
- 记录顶点名称的映射关系

### 主要算法步骤

1. **构造残差图** (`residual_level_graph`):
   - 通过 BFS 对残差图分层
   - 只保留有剩余容量的边

2. **增广迭代** (`augment_iteration`):
   - 通过 DFS 在分层图中寻找增广路径
   - 沿路径添加流，移除饱和边

3. **最大流计算** (`compute_max_flow`):
   - 反复执行增广迭代，直到找不到增广路径
   - 返回总流量

4. **最小割分割** (`partition`):
   - 使用反向 BFS 找出从汇点可达的顶点
   - 分为"可达"和"不可达"两个分割集合

### 功能列表

- **最大流算法**: 使用 Dinic 算法，复杂度为 O(V²E)
- **最小割计算**: 基于最大流最小割定理
- **图分割**: 将顶点划分为两个集合
- **溢出检测**: 检查流值是否超过 INF 阈值或无界
- **顶点名称映射**: 支持字符串标签的顶点

### 应用场景

根据注释，用于 **functorch 分区器**中分割计算图为前向和反向子图。
