## 文件概述

`c10/util/generic_math.h` 是 PyTorch 的 c10 库中的数学工具头文件，提供了跨平台的数学运算实现。

## 主要功能

该文件实现了三个核心数学运算函数，用于处理 Python 风格的除法和取模操作：

### 1. **div_floor_floating** (第 33-57 行)
- 实现浮点数的向下取整除法（floor division）
- 遵循 Python 的 `__floordiv__` 语义：`a == (a // b) * b + remainder(a, b)`
- 处理除零边界情况，返回标准 IEEE 结果
- 通过调整商和余数的关系来保证数学准确性

### 2. **div_floor_integer** (第 59-70 行)
- 实现整数的向下取整除法
- 当被除数和除数符号不同时，若有余数则从商中减 1
- 确保整数除法遵循 Python 的取整规则

### 3. **div_mod** (第 72-100 行)
- 分两个重载版本处理取模操作：
  - **浮点版本**：使用 `std::fmod`，处理符号匹配和除零情况
  - **整数版本**：使用 `%` 操作符，调整符号使结果与除数同号
- 确保取模结果符号与除数一致（Python 风格）

## 关键特性

- **跨平台兼容**：支持 CUDA、HIP 和标准 C++
- **Python 语义对齐**：所有运算遵循 Python 的数学规则
- **Header-only**：可直接编译到使用代码中
- **UBSan 检查忽略**：浮点除零操作标记为已检查

## 核心要点

- 实现 Python 风格的 floor division 和 modulo 运算
- 处理浮点和整数两种数据类型
- 保证除零、符号匹配等边界条件的正确处理
- 支持 CUDA/HIP 异构计算和标准 CPU 计算
