这个文件实现了 CUDA 设备端的断言检查机制，用于在 GPU 核函数中捕获和记录断言失败。

**核心功能：**

- **条件编译开关**：`TORCH_USE_CUDA_DSA` 控制设备端断言是否启用
- **字符串复制函数** `dstrcpy()`：安全地将字符串从源复制到目标，限制最大长度为 `C10_CUDA_DSA_MAX_STR_LEN-1`，防止缓冲区溢出
- **断言失败记录** `dsa_add_new_assertion_failure()`：当断言失败时原子性地记录失败信息到共享内存缓冲区，包括：
  - 断言条件表达式
  - 文件名、函数名、行号
  - 调用者 ID
  - 块索引和线程索引（用于定位失败位置）
- **缓冲区管理**：使用原子操作确保多个线程可以同时记录失败，当缓冲区满后静默忽略新的失败记录
- **宏定义** `CUDA_KERNEL_ASSERT2()`：
  - 启用 DSA 时：记录断言失败后立即返回（不停止内核，但数据不可靠）
  - 禁用 DSA 时：退化为普通 C `assert()`
- **设计目的**：允许主机端通过 UVM 检查设备端缓冲区，发现并报告 GPU 核函数中的断言失败
