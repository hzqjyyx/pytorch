- **文件目的**：提供将维度列表转换为位集的工具函数，用于处理多维张量操作
- **核心函数**：`dim_list_to_bitset()` - 将可选的维度数组转换为 64 位的位集表示
- **主要功能**：
  - 接收可选的维度列表和张量的维度数
  - 如果提供了维度列表，逐个处理每个维度（支持负索引包装）
  - 检查重复维度，防止同一维度出现多次
  - 如果未提供维度列表，则将所有维度标记为已选中
  - 返回一个 `std::bitset<64>` 对象，其中每一位表示对应维度是否被选中
- **限制**：仅支持最多 64 个维度的张量
- **设计原因**：在单独文件中实现以避免 Windows 上 bitset 与操作符重载的奇怪交互问题
