SequenceNumber 是一个线程局部的序列号管理模块，用于追踪操作执行顺序。

**核心设计**：
- 使用 `thread_local uint64_t sequence_nr_` 存储每个线程的序列号
- 序列号从 0 开始，单调递增

**API 接口**：
- `peek()`：返回当前序列号，不修改状态
- `get_and_increment()`：返回当前序列号，然后将其加 1

**主要用途**：
- 在自动求导（autograd）中链接前向和反向传播操作
- 为观察者框架（observers framework）提供操作顺序标识

**关键特性**：
- 线程安全：每个线程维护独立的序列号计数器
- 导出符号：`TORCH_API` 标记使其在共享库中可见

**应用场景**：
- 追踪计算图中操作的执行顺序
- 帮助调试和性能分析
- 支持操作级别的观察和监控
