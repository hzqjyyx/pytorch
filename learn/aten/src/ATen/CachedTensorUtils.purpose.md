## 主要功能分析

这两个文件实现了一个**缓存张量管理系统**，用于追踪和管理在特定系统（如 CUDA Graphs）中持久化的张量。

### 核心机制

**数据结构：**
- 使用 `ska::flat_hash_map` 维护一个全局缓存映射，以 `TensorImpl*` 为键
- 通过弱引用 (`weak_intrusive_ptr`) 保持张量活跃，避免循环引用
- 使用互斥锁 (`std::mutex`) 保护并发访问

**主要问题解决：**

1. **dtype 转换缓存失效**：CUDA Graphs 中的静态张量 `TensorImpl` 在迭代间不变，如果缓存 dtype 转换会导致错误结果

2. **引用计数虚高**：缓存系统本身会增加额外的引用计数，干扰以下操作：
   - 缓冲区原位操作（buffer inplacing）
   - 张量唯一性检查

### API 接口

| 函数 | 用途 |
|------|------|
| `is_cached_tensor()` | 检查张量是否在缓存中 |
| `add_cached_tensor()` | 添加张量到缓存 |
| `remove_cached_tensor()` | 从缓存移除张量 |
| `set_cached_tensors_enabled()` | 全局启用/禁用缓存系统 |
| `adjusted_use_count()` | 返回调整后的引用计数（扣除缓存引用） |

### 设计特点

- **延迟启用**：默认禁用，仅在需要系统（如 cudagraphs）启用时激活，避免常规路径的性能开销
- **弱引用策略**：不增加张量生命周期，允许正常垃圾回收
- **线程安全**：所有操作都在互斥锁保护下进行

---

### 功能概览

- 为 CUDA Graphs 等系统中的持久化张量提供缓存管理
- 防止无效的 dtype 转换缓存
- 提供准确的张量引用计数，支持梯度缓冲区窃取和张量唯一性检查
- 通过全局开关实现条件启用，保证非启用场景零开销
