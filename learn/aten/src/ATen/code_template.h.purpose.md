这个文件实现了一个简单的模板引擎，用于代码生成。主要包含两个核心组件：

## TemplateEnv - 模板环境

存储模板变量及其值的映射表，支持三种数据类型：
- **字符串**：通过 `s(key, value)` 设置，`s(key)` 获取
- **数字**：通过 `d(key, value)` 设置，内部转为字符串存储
- **字符串列表**：通过 `v(key, value)` 设置，`v(key)` 获取

支持环境链式查找：如果当前环境找不到 key，会递归到父环境查找。

## CodeTemplate - 模板处理器

解析并替换模板文本中的变量占位符：

**基本语法**：
- `$identifier` 或 `${identifier}` - 替换为对应变量值

**智能替换规则**：

1. **块级替换**（变量在行首空白后）：
   - 字符串：保持缩进插入多行内容
   - 列表：每个元素独占一行，保持相同缩进

2. **行内替换**（变量在非空白字符后）：
   - 字符串：直接插入
   - 列表：逗号分隔 `item1, item2, item3`

3. **逗号控制**：
   - `${,foo}` - 列表非空时在前面加逗号
   - `${foo,}` - 列表非空时在后面加逗号

**核心方法**：
- `format(env)` - 遍历模板文本，识别 `$` 标记，解析变量名，根据上下文（缩进、空白）选择替换策略

**使用场景**：PyTorch 代码生成系统，根据配置文件动态生成 C++ 算子代码、分发逻辑等。
