# CPUApplyUtils.h 核心功能

这个文件提供了一套用于在 CPU 上对张量进行逐元素操作的工具函数。核心思想是优化内存访问模式，通过识别和利用连续内存区域来提高性能。

## 核心策略

文件开头的注释（12-40行）描述了基本策略：

1. **识别连续区域**：从最外层维度开始，找到数据不再连续的维度边界，将张量分为外部连续张量 A 和内部张量 B

2. **优化遍历**：对于内部张量 B 的每个索引，计算存储偏移量后，可以直接循环处理 A 的所有元素，无需按照 A 的步长顺序访问

3. **维度合并**：将内存中连续的维度合并，减少嵌套循环层数

## 主要组件

### 迭代器结构

- **`strided_tensor_iter_fixed<T, N>`** (56-89行)：固定维度（≤8维）的张量迭代器，使用栈上数组
- **`strided_tensor_iter<T>`** (91-115行)：动态维度的张量迭代器，使用 vector

两者都存储：
- `data_`：数据指针
- `counter_`：当前索引计数器
- `sizes_`：各维度大小
- `strides_`：各维度步长
- `dim_`：合并后的有效维度数

### 辅助函数

- **`sort_strides`** (42-54行)：按步长降序重排张量维度
- **`_apply_preamble`** (144-154行)：检查设备类型、布局、元素数量是否一致
- **`iterate`** (165-170行)：推进迭代器指定步数
- **`iterate_continue`** (176-180行)：检查是否可继续迭代
- **`iterate_overflow`** (195-208行)：处理维度溢出，类似多维计数器进位
- **`forward`** (212-222行)：将迭代器前进指定偏移量
- **`max_iterate_size`** (186-191行)：计算可一次迭代的最大元素数

### 核心操作函数

**`apply_op`** (235-257行)：
- 处理 0 维张量特殊情况
- 使用 `forward` 设置起始偏移
- 循环调用操作符 `op`，每次迭代一个元素
- 使用 `iterate_overflow` 处理维度边界

### 公共 API

提供三个模板函数用于 2/3/4 个张量的逐元素操作：

- **`CPU_tensor_apply2`** (269-288行)
- **`CPU_tensor_apply3`** (290-315行)  
- **`CPU_tensor_apply4`** (317-350行)

这些函数：
1. 调用 `_apply_preamble` 进行前置检查
2. 根据最大维度数选择固定或动态迭代器（8维为分界）
3. 调用 `apply_op` 执行实际操作

## 使用示例

注释中给出的例子（264-266行）：计算 `a = b * c`

```cpp
op = [](scalar* a_val, const scalar* b_val, const scalar* c_val) { 
    a_val[0] = b_val[0] * c_val[0]; 
};
```

操作符接收与张量数量相同的指针参数，对当前位置的元素执行操作。
