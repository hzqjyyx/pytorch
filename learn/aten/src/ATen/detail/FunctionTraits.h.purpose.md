- **核心功能**：通过模板特化实现函数特征提取，能够在编译期获取任意可调用对象的参数类型、返回类型和参数个数

- **主要组件**：
  - `function_traits`：基础模板，通过递归特化处理多种函数类型（自由函数、成员函数、lambda、函数指针等）
  - `nullary_function_traits`、`unary_function_traits`、`binary_function_traits`：便利类，为特定参数数量的函数提供简化接口
  - `invoke_traits`：扩展版本，为 `c10::guts::invoke` 调用方式进行适配，将成员函数的隐式 `this` 转化为显式的第一个参数

- **关键特化处理**：
  - 引用和指针剥离（通过递归特化）
  - const 成员函数识别
  - 类成员函数指针
  - lambda 表达式（通过 `operator()` 委托）

- **使用场景**：编译期反射，用于动态调用、参数验证、类型推导等需要函数签名信息的场景
