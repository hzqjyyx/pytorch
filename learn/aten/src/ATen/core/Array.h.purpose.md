# ATen/core/Array.h 功能分析

**Array** 是一个固定大小的数组模板，设计用于在 CPU 和 GPU 代码中都能使用。

## 核心组成

- **模板参数**：`T`（元素类型）和 `size_`（固定数组大小）
- **存储**：内部使用原生 C 数组 `T data[size_]` 存储元素
- **访问接口**：通过 `operator[]` 提供只读和可读写访问
- **默认操作**：默认构造、拷贝构造、赋值运算符、移动语义、析构函数
- **初始化构造器**：`Array(T x)` 可用同一值初始化整个数组
- **静态方法**：`size()` 返回数组的编译时大小
- **编译期常量**：`size_` 作为模板参数，允许编译器优化

## 关键特性

• 既可在主机代码运行，也可在 CUDA GPU 核函数中运行（C10_HOST_DEVICE 宏）
• 固定大小特性适合 GPU 代码（避免动态内存分配开销）
• 提供标准数组接口（支持 `[]` 操作符）
• 支持批量初始化（用同一值填充）
• 简洁轻量级设计，最小化编译开销
