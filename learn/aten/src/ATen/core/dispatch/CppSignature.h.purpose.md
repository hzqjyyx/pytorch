CppSignature 类是一个 C++ 函数签名的运行时 RTTI（运行时类型信息）包装器。

**主要功能：**

- **存储函数签名信息** - 使用 `std::type_index` 持有函数类型的 RTTI 数据
- **规范化函数类型** - 通过 `make()` 模板方法，将函数指针、lambda、仿函数等统一转换为标准函数类型
- **移除 DispatchKeySet 参数** - 在生成签名前自动剥离第一个 DispatchKeySet 参数，确保不同调用约定的同一操作符注册时签名一致
- **比较函数签名** - 通过 `operator==` 和 `operator!=` 支持签名相等性判断，考虑了不同编译单元中 RTTI 实例不同的情况
- **获取人类可读名称** - 提供 `name()` 方法返回反 mangled 的函数签名字符串用于调试
- **标准容器兼容** - 支持拷贝构造、移动语义和赋值操作

**核心设计目的：**
在 PyTorch 分发系统（Dispatcher）中验证和匹配注册的算子实现是否具有兼容的 C++ 函数签名。
