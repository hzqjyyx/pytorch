# AliasInfo 类 - 别名信息数据结构

## 核心功能

**AliasInfo** 是一个用于存储和管理操作参数别名信息的数据结构。它追踪参数在操作执行前后的别名关系。

## 主要成员和方法

### 别名集合管理
- `beforeSets()` / `afterSets()` - 获取执行前后的别名集合
- `addBeforeSet()` / `addAfterSet()` - 添加别名集合
- `beforeSet()` - 获取单个别名集合（要求只有一个）
- `wildcardSet()` - 代表可以与任何东西产生别名的特殊符号

### 写入标记
- `setIsWrite()` / `isWrite()` - 标记和查询是否为写操作

### 嵌套类型支持
- `addContainedType()` / `containedTypes()` - 管理嵌套类型的别名信息
  - 用于列表、映射等复杂类型的递归别名追踪

### 工具函数
- `operator==` - 比较两个 AliasInfo 对象
- `operator<<` - 格式化输出别名信息
- 自定义 `std::hash` - 支持在哈希容器中使用

## 功能总结

- **别名追踪**: 记录操作参数在执行前后的别名关系
- **嵌套支持**: 通过递归结构支持复杂类型的别名注解
- **通配符**: 支持 `alias::*` 通配符表示与任意别名相关
- **哈希计算**: 使用 XOR 组合哈希值（保证交换律）以支持无序集合
