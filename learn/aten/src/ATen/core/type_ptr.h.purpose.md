**SingletonTypePtr 模板类**

这是一个兼容性包装器，为现有代码提供类似 `shared_ptr` 的接口，但底层使用原始指针。

**核心设计**

- 隐式构造函数接收原始指针 `T*`，存储在 `repr_` 成员中
- 显式构造函数禁止接收 `shared_ptr`（为满足 Pybind11 而存在，但会断言失败）

**提供的操作符**

- `operator*()` - 解引用指针，获取对象引用（非 `void` 类型）
- `operator->()` - 箭头操作符，访问成员
- `get()` - 返回原始指针
- `operator bool()` - 支持布尔转换，检查指针是否非空

**比较操作**

- `operator==` 和 `operator!=` - 支持两个 `SingletonTypePtr` 的比较（通过转换为 `void*` 比较地址）

**主要用途**

- 允许依赖 `shared_ptr` 接口的现有代码与原始指针协作
- 简化从 `shared_ptr` 到原始指针的迁移过程

**要点**

- 不管理内存生命周期（只是包装指针）
- 类型灵活（支持模板参数 `T`）
- 提供基础指针操作的最小子集
- 主要是兼容性工具，非生产级别的智能指针替代品
