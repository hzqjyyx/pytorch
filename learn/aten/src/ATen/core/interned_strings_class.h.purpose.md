- **InternedStrings 类**：管理字符串到符号的映射和反向映射
- **核心方法**：
  - `symbol(const std::string& s)`：将字符串转换为 Symbol 对象
  - `string(Symbol sym)`：将 Symbol 转换回字符串对（命名空间和名称）
  - `ns(Symbol sym)`：获取符号所属的命名空间
- **内部存储**：
  - `string_to_sym_`：哈希表，存储字符串→符号的映射
  - `sym_to_info_`：向量，存储每个符号的命名空间和限定/非限定名称
- **并发安全**：使用 `mutex_` 保护共享数据
- **设计目的**：实现符号的字符串化和反字符串化，支持命名空间管理
