**QuantizerBase.h 主要功能：**

- **量化器基类** - 定义了 `Quantizer` 结构体，作为所有量化方案的基类
- **量化方案抽象** - 通过虚函数 `qscheme()` 定义每种量化类型的唯一标识
- **量化/反量化接口** - 提供 `quantize()` 和 `dequantize()` 虚函数用于浮点张量和量化张量之间的转换
- **比较操作** - 通过 `equalTo()` 虚函数支持量化器之间的相等性判断
- **标量类型管理** - 存储和管理量化张量的数据类型（ScalarType）
- **引用计数** - 使用 `c10::intrusive_ptr` 实现自动内存管理，支持多个张量共享同一量化器
- **不可变性保证** - 量化器应为不可变对象，多个张量可安全共享
- **具体实现指导** - 注释说明添加新的量化类型时需同步更新 QScheme 枚举
