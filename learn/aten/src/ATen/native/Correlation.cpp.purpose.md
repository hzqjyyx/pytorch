## 文件主要功能

**Correlation.cpp** 实现了两个统计计算函数：

### `cov()` - 协方差矩阵计算
- 计算输入张量的协方差矩阵
- 支持最多2维输入（自动转换1维为2D）
- 支持频率权重 `fweights`（整数类型）和观测权重 `aweights`（浮点类型）
- 支持 Bessel 校正参数 `correction`
- 计算流程：
  1. 验证输入维度和数据类型
  2. 验证权重有效性和维度匹配
  3. 计算加权平均值
  4. 计算规范化因子（考虑校正和权重）
  5. 中心化数据并计算协方差矩阵
  6. 用规范化因子除以得到最终结果

### `corrcoef()` - 相关系数矩阵计算
- 基于协方差矩阵计算皮尔逊相关系数
- 处理标量和矩阵两种情况
- 计算流程：
  1. 调用 `cov()` 获取协方差矩阵
  2. 对标量情况返回 NaN/1 处理
  3. 提取对角线元素（方差）计算标准差
  4. 用标准差归一化协方差矩阵
  5. 裁剪值到 [-1, 1] 范围（浮点精度问题）
  6. 复数情况分别处理实部和虚部

### 关键特性
- 支持复数张量（使用共轭转置）
- 权重可选，支持组合使用
- 包含完整的输入验证和错误检查
- 浮点精度处理（值范围裁剪）
