# ConvUtils.h 文件分析

这个文件定义了量化卷积操作的输出形状计算工具。

**主要功能：**

- **MakeConvOutputShape 模板函数** - 通用接口，根据卷积参数（批次、输出通道、输入形状、核大小、步长、填充、膨胀）计算输出张量的形状

- **2D 卷积专门化实现** - 针对 2D 卷积，使用公式计算输出高度和宽度：`(H + 2*padding - dilation*(kernel-1) - 1) / stride + 1`

- **3D 卷积专门化实现** - 针对 3D 卷积，对深度、高度、宽度分别应用相同的输出形状计算公式

- **条件编译** - 仅在 CUDA 或 PyTorch QNNPACK 后端启用时编译，避免重复符号导出

- **返回 SmallVector** - 使用栈分配的小向量存储输出形状，提高性能
