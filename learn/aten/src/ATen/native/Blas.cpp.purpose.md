**文件主要功能**

`Blas.cpp` 实现了基础线性代数子程序（BLAS）相关的核心操作：

- **addmv（加法矩阵向量乘法）**：计算 `result = beta * self + alpha * (mat @ vec)`，支持CPU执行，包含元函数定义和具体实现
- **mv（矩阵向量乘法）**：计算 `mat @ vec`，通过调用 `addmv_` 实现，beta=0
- **dot（点积）**：计算两个1D张量的点积，处理复数共轭情况，支持MKLDNN加速
- **vdot（向量点积）**：复数向量的点积（第一个向量取共轭），实数情况委托给 `dot`

**关键技术细节**

- 使用 `AT_DISPATCH_*` 宏处理多种数据类型（float, double, complex, bfloat16, half等）
- 通过 `gemv` 模板函数调用底层BLAS实现
- 支持MKLDNN优化路径，当条件满足时使用高效矩阵乘法
- 处理特殊情况：零张量、空矩阵、非连续内存布局等
- 包含步长检查和内存优化（避免不必要的拷贝）

**输入验证与优化**

- 检查张量维度和大小匹配性
- 优化三种矩阵步长情况：行优先、列优先、非连续
- 保留命名张量信息的传播
