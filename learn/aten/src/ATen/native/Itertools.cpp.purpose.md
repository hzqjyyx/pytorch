这个文件实现了三个张量迭代相关的核心函数：

**cartesian_prod** (第46-58行)
- 计算多个1D张量的笛卡尔积
- 使用 `meshgrid` 生成所有可能的坐标组合
- 展平后按列堆叠，返回 N×M 的张量（N为输入张量个数，M为笛卡尔积结果数）

**combinations** (第60-73行)
- 从1D张量中生成 r 元组合
- 支持有放回和无放回两种模式
- 通过 `_triu_mask` 过滤掉不满足条件的组合
- 返回堆叠后的组合结果

**_triu_mask** (第24-40行)
- 辅助函数，生成上三角掩码
- 对于无放回模式：确保 i < j < k < ...（严格递增）
- 对于有放回模式：确保 i <= j <= k <= ...（非递减）

**关键特点：**
- 基于 `meshgrid` 生成所有可能性，再用掩码过滤
- 使用 `masked_select` 和 `stack` 重组张量
- 所有操作保持张量的数据类型和设备属性
