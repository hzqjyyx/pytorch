# NonEmptyUtils.h 文件分析

这个文件提供了一组实用工具函数，用于处理空张量（empty tensor）的维度、大小和步长等属性。

## 核心函数

**`ensure_nonempty_dim(int64_t dim)`**
- 确保维度至少为 1
- 使用 `std::max` 返回 `dim` 和 1 中的较大值
- 当处理 0 维张量时，避免负数或零维度问题

**`ensure_nonempty_size(const TensorBase &t, int64_t dim)`**
- 获取张量在某个维度上的大小
- 如果张量是 0 维的，返回 1；否则返回实际的 size(dim)

**`ensure_nonempty_stride(const TensorBase &t, int64_t dim)`**
- 获取张量在某个维度上的步长
- 如果张量是 0 维的，返回 1；否则返回实际的 stride(dim)

**`ensure_nonempty_vec(IdxVec vec)`**
- 确保向量非空
- 如果输入向量为空，添加一个值 1
- 如果已有元素，直接返回原向量

## 主要功能

- **处理 0 维张量**：提供统一的接口来处理标量张量的特殊情况
- **避免越界**：防止访问 0 维张量时的索引错误
- **简化 API**：通过这些工具函数，上层代码无需重复检查张量维度

## 应用场景

- 张量形状操作和广播
- 内存布局计算
- 索引和切片操作
