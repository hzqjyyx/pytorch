这个文件实现了3D卷积中的 **vol2col** 和 **col2vol** 转换操作：

**vol2col函数 (8-56行)**
- 将3D体积数据（volume）转换为列矩阵（column matrix）
- 对每个卷积核位置，提取对应的输入数据块并展开成列
- 支持padding、stride、dilation等卷积参数
- 如果索引越界则填充0

**col2vol函数 (58-107行)**
- vol2col的逆操作，将列矩阵数据累加回3D体积
- 用于反向传播时梯度的汇聚
- 初始化输出为0，然后逐个累加每个卷积块的贡献

**核心特点：**
- 支持任意数据类型（模板化）
- 处理3D卷积的所有参数：通道数、深度、高度、宽度、卷积核大小、padding、stride、dilation
- 通过循环逐元素计算，无SIMD优化
- 使用int64_t避免整数溢出

**主要用途：**
- 将3D卷积转换为矩阵乘法（GEMM）以提高效率
- 前向传播：输入转换 → GEMM → 输出转换
- 反向传播：梯度累加回输入
