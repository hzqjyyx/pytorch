## 文件概述

**SortImpl.cu** 是 PyTorch ATen 库中的一个 CUDA 实现文件，主要包含一个关键函数：`infer_dense_strides_dim_last`

## 主要功能分析

### 函数目的
这个函数用于**推断（infer）新的张量步长（strides）**，在保持指定维度为最后一维的条件下，生成密集（contiguous）内存布局的步长。

### 函数工作流程

1. **准备阶段** (第8-17行)
   - 获取张量的维度数 `ndim`
   - 复制原始步长数组
   - 将目标维度 `dim` 的步长设为 `-1`（标记为特殊）
   - 创建原始维度的索引映射 `original_dim`

2. **排序阶段** (第18-21行)
   - 使用 `thrust::stable_sort_by_key` 按**步长值降序排序**
   - 排序时保留维度索引对应关系
   - 目标维度因为被设为 `-1`，会排到最后

3. **生成新步长** (第23-29行)
   - 从排序后的维度顺序生成**连续的新步长**
   - 从最后一维开始，逐维生成：`new_strides = [1, size[0], size[0]*size[1], ...]`
   - 这样保证了内存的连续性

4. **反排序** (第31-33行)
   - 将计算出的新步长映射回原始维度顺序
   - 确保返回的步长与原始维度对应

### 应用场景
这个函数通常用于：
- 优化张量内存布局
- 确保某个维度始终为最后一个维度的同时，保持内存连续性
- 在排序操作后调整张量的步长信息
