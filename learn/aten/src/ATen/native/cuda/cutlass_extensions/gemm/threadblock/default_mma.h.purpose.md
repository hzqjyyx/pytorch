这个文件定义了 CUTLASS 库中的默认矩阵乘法（MMA）配置，针对不同的数据类型和硬件架构进行特化。

**主要内容：**

1. **fp16 激活 + int8 权重特化** (第35-85行)
   - 使用 `DqMma`（去量化MMA）处理量化权重
   - 支持可配置的矩阵布局和对齐方式

2. **fp16 激活 + int4 权重特化** (第110-160行)
   - 类似的特化结构但针对 4 比特权重
   - 支持更激进的量化

3. **多阶段管道版本** (第187-322行)
   - 针对不同 `kStages` 参数的 int8 和 int4 权重特化
   - 包含共享内存清除选项

4. **fp16 x fp16 Ampere 特化** (第351-422行)
   - 针对 SM80（Ampere架构）优化
   - 使用多阶段MMA避免寄存器溢出
   - 支持数据收集（Gather）操作

**核心功能：**

- 将通用 `DefaultMma` 模板特化为具体的硬件和数据类型组合
- 配置线程块级别的矩阵乘法操作
- 定义迭代器（IteratorA/B）访问矩阵数据
- 配置共享内存和计算策略以优化性能
- 支持量化推理（int8/int4权重）的加速计算
