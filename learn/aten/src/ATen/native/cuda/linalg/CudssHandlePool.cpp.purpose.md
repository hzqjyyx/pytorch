- **创建和销毁 cuDSS 句柄**：定义了 `createCudssHandle()` 和 `destroyCudssHandle()` 两个函数，用于生命周期管理
- **句柄池管理**：使用 `DeviceThreadHandlePool` 模板创建 `CudssPoolType`，实现句柄的复用和缓存
- **获取当前设备句柄**：`getCurrentCudssHandle()` 函数为当前线程和 CUDA 设备获取一个可用句柄
- **线程本地存储**：每个线程维护独立的 `PoolWindow`，避免跨线程竞争和初始化问题
- **流关联**：获取句柄后立即将其与当前 CUDA 流绑定，确保操作在正确的流上执行
- **Windows 兼容性**：使用懒初始化策略避免 Windows 上的初始化死锁问题
- **条件销毁**：在 `NO_CUDNN_DESTROY_HANDLE` 宏定义时跳过句柄销毁，解决某些环境下上下文销毁顺序问题
