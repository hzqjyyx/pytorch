## 文件概述

这个文件实现了 **RReLU（随机泄漏ReLU）激活函数的带噪声版本**，专门为 CUDA GPU 优化。

## 核心功能分解

### 1. **主要 CUDA 核函数** (`rrelu_with_noise_cuda_kernel`, 第 23-68 行)

这是GPU上的核心计算逻辑：
- 为每个元素生成随机噪声（使用 Philox 随机数生成器）
- 对于**负数输入**：乘以随机噪声 (`output = input × random_noise`)
- 对于**正数输入**：保持不变 (`output = input`)
- 同时将噪声值存储在 `noise` 张量中

关键特性：
- 使用 `unroll_factor` 展开循环以提高性能（double 类型用 2，其他用 4）
- 多线程并行处理多个元素

### 2. **训练模式处理** (`_rrelu_with_noise_cuda_train`, 第 71-135 行)

这个函数执行实际的 RReLU 训练：
- 获取随机数生成器状态
- 计算网格和线程块配置
- 根据数据类型（double/float/half）选择合适的随机数生成方法
- 启动 CUDA 核函数处理数据

### 3. **公共接口** (第 137-190 行)

提供三种调用方式：

| 函数 | 说明 |
|-----|------|
| `rrelu_with_noise_out_cuda` | 支持输出张量、支持训练/推断模式 |
| `rrelu_with_noise_cuda` | 创建新的输出张量 |
| `rrelu_with_noise_cuda_` | 原地修改输入张量 |

**训练模式 vs 推断模式**：
- **训练**：添加随机噪声
- **推断**：使用平均斜率执行普通的 leaky_relu

## 典型使用场景

RReLU 常用于：
- 防止神经网络过拟合（通过添加随机性）
- 提高模型的鲁棒性

这个实现充分利用了 GPU 的并行处理能力，通过 CUDA 线程块和网格来处理大量数据。
