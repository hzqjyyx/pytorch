这个文件定义了参数扩展工具函数，用于处理卷积操作中的参数维度匹配问题。

**主要功能：**

- **`_expand_param_if_needed<T>`** - 通用模板函数，处理参数列表扩展逻辑
  - 如果参数只有一个元素，将其复制扩展到 `expected_dim` 个元素
  - 如果参数个数与期望维度不符且不是单元素，抛出错误提示
  - 否则将参数转换为向量返回

- **`expand_param_if_needed` (整数版本)** - 处理 `IntArrayRef` 类型参数，用于标准整数数组

- **`expand_param_if_needed` (符号整数版本)** - 处理 `SymIntArrayRef` 类型参数，用于符号整数（支持动态形状表示）

**典型使用场景：**

- 卷积核大小：`kernel_size=3` 自动扩展为 `[3, 3]`（二维）或 `[3, 3, 3]`（三维）
- 填充、步长等参数的规范化处理
