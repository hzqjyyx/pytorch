这是一个 CUDA 核函数定义文件，用于实现高效的多头注意力（Flash Attention）计算。

**主要功能：**

- **自动生成的文件**：由 `generate_kernels.py` 脚本生成，包含针对不同 GPU 架构优化的核函数实现
- **多架构支持**：为 SM50、SM70、SM75 等不同 CUDA 计算能力版本生成专门的核函数
- **三种配置变体**：
  - `64x64_rf`：64×64 块配置，使用寄存器存储（Register File）
  - `32x128_rf`：32×128 块配置，使用寄存器存储
  - `32x128_gmem`：32×128 块配置，使用全局内存存储
- **float32 精度**：针对单精度浮点数数据类型优化（`_f32_`）
- **非对齐内存访问**：支持未对齐的内存访问模式（`notaligned`）
- **架构版本检查**：每个核函数包含条件编译指令，在 GPU 不匹配时打印错误信息并返回
- **性能优化**：使用 CUTLASS 库提供的高性能模板实现，包括块大小和线程数的优化配置
