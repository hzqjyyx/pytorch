这个文件定义了一组针对不同 CUDA 计算能力（SM 版本）的高效注意力机制反向传播内核：

- **自动生成文件**：由 `generate_kernels.py` 脚本自动生成，文件头注释明确说明
- **5 个全局内核函数**：分别针对 SM50、SM70、SM75、SM80 架构
- **内核规格多样**：
  - SM50/SM70 使用 64×64 块大小
  - SM70/SM75/SM80 使用 128×64 块大小
  - 所有内核的 K（序列维度）固定为 65536
- **AttentionBackwardKernel 模板实例化**：使用 CUTLASS 库的通用反向传播内核模板，针对 half_t（FP16）数据类型优化
- **架构特定编译**：每个内核包含条件编译指令，确保只在目标 SM 架构范围内执行
- **动态错误检查**：运行时检查实际 GPU 架构与编译期目标架构匹配，不匹配时打印 FATAL 错误信息
- **块级任务分配**：通过 `p.advance_to_block()` 实现多块协作处理，避免线程束重复计算
