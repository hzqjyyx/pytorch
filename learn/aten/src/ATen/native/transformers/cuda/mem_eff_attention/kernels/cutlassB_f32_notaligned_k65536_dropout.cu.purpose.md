- **自动生成文件**：由 `generate_kernels.py` 脚本自动生成，用于 CUDA 注意力机制的反向传播计算

- **三个 GPU 架构的核函数**：分别针对 SM50、SM70、SM75 架构优化，每个函数处理不同的 CUDA 计算能力范围

- **核函数参数**：
  - 数据类型：float32
  - 块大小：64×64
  - 序列长度：65536
  - 启用 Dropout：在反向传播中应用随机失活掩码

- **架构检查机制**：每个核函数包含条件编译指令，验证运行时 CUDA 架构与编译时匹配，不匹配则输出错误信息

- **核心逻辑**：调用 `AttentionBackwardKernel::attention_kernel()` 执行具体的反向传播计算，包括梯度计算和动态规划优化

- **线程配置**：使用 `__launch_bounds__` 指定每个块的线程数和每个 SM 的最小块数，优化 GPU 资源利用率
