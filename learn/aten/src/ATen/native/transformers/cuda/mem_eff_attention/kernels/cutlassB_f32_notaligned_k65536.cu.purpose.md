这个文件定义了三个 CUDA 全局内核函数，用于实现高效注意力机制的反向传播计算。每个内核针对不同的 GPU 架构优化：

• **SM 50 内核** (`fmha_cutlassB_f32_notaligned_64x64_k65536_sm50`): 支持计算能力 5.0-6.9 的 GPU，处理 64×64 块大小和 65536 个特征维度的反向传播

• **SM 70 内核** (`fmha_cutlassB_f32_notaligned_64x64_k65536_sm70`): 支持计算能力 7.0-7.4 的 GPU（Volta 架构），针对该架构进行优化

• **SM 75 内核** (`fmha_cutlassB_f32_notaligned_64x64_k65536_sm75`): 支持计算能力 7.5-7.9 的 GPU（Turing 架构），针对该架构进行优化

• **架构检查机制**: 每个内核包含编译时架构检查 (`#if __CUDA_ARCH__`)，确保只在目标 GPU 架构上执行

• **浮点精度**: 使用单精度浮点数 (float/f32) 进行计算

• **参数处理**: 通过 `advance_to_block()` 机制分配工作块，提高并行效率

• **自动生成**: 文件由 `generate_kernels.py` 自动生成，避免手动维护多个架构变体
