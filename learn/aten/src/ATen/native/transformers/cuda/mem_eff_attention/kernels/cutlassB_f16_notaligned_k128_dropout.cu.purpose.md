这个文件定义了多个 CUDA 核函数，用于高效的多头注意力机制(FMHA)的反向传播计算。

**主要功能：**

- **自动生成文件**：由 `generate_kernels.py` 脚本自动生成，包含针对不同 GPU 架构优化的核函数实现

- **多架构支持**：为 SM50、SM70、SM75 等多个 CUDA 计算能力版本生成专门的核函数，确保在不同 GPU 上都能正确执行

- **反向传播注意力计算**：每个核函数都是 `AttentionBackwardKernel` 模板的实例化，用于计算注意力机制的梯度

- **参数配置多样化**：
  - 支持半精度浮点数(FP16)计算
  - 配置不同的分块大小(如 128x64、64x64)
  - 支持 Dropout 正则化
  - 非对齐内存访问优化

- **运行时检查**：每个核函数包含 `__CUDA_ARCH__` 条件编译检查，确保只在适配的 GPU 架构上执行，否则打印错误信息

- **线程调度优化**：使用 `__launch_bounds__` 指定线程块大小和最小块数，优化 GPU 的线程调度和资源利用
