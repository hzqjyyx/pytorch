这个文件实现了一个 CUDA 共享内存加载器，用于在 CUTLASS 框架下高效地将全局内存中的数据块加载到共享内存。

**核心结构：**

`TileSmemLoader` 是一个模板类，通过三个主要的类型别名组织数据加载流程：

1. **SmemTile** - 共享内存缓冲区，大小为 `ThreadblockTileShape::kCount` 个 `scalar_t` 类型元素

2. **ThreadMap** - 线程映射策略，使用 `PitchLinearStripminedThreadMap` 定义线程如何协同访问内存，参数包括：
   - 行列维度（列连续，行条纹化）
   - 参与线程数
   - 每个线程的元素访问宽度

3. **GmemTileIterator** - 全局内存迭代器，支持谓词化访问（可以跳过边界外的元素）

4. **SmemTileIterator** - 共享内存迭代器，规则的瓦片迭代方式

**工作流程：**

`load()` 静态方法是核心操作：
- 声明片段缓冲区 (`tb_frag`) 用于存储加载的数据
- 从全局内存迭代器加载数据到片段
- 将片段数据存储到共享内存迭代器
- 执行 `__syncthreads()` 确保所有线程同步

**主要用途：**

- 高效的块级内存传输（Global → Shared Memory）
- 支持非对齐和边界处理的安全加载
- 为后续的计算阶段准备数据，广泛应用于注意力机制（attention）的 CUDA 优化实现

**关键特点：**

- 使用 CUTLASS 库的抽象化组件，避免手写复杂的内存访问模式
- 模板设计提供灵活的标量类型、瓦片大小、线程配置组合
- 谓词化加载处理不规则边界情况
- 显式线程同步保证内存可见性
