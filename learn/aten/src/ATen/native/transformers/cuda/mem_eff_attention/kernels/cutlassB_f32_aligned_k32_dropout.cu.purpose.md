这个文件定义了一系列 CUDA 内存高效注意力机制的反向传播内核函数。

## 核心功能

- **自动生成文件**：文件由 `generate_kernels.py` 脚本自动生成，包含多个针对不同 GPU 架构优化的内核版本

- **多架构支持**：为 SM50、SM70、SM75、SM80 等不同 NVIDIA GPU 架构提供专用内核实现

- **注意力机制反向传播**：实现 `AttentionBackwardKernel` 模板，计算注意力层的梯度

- **参数配置**：
  - `float` 数据类型（32位浮点数）
  - `aligned` 内存对齐访问模式
  - `k32` 表示头维度为32
  - `dropout` 支持 dropout 正则化

- **线程块优化**：每个内核使用 `__launch_bounds__` 指定线程数和每个 SM 的最小块数，以优化 GPU 利用率

- **架构检查**：在 `#ifdef __CUDA_ARCH__` 条件下验证编译架构是否匹配目标 GPU，防止在不兼容的硬件上运行

- **特殊 CUDA 12.04 处理**：针对 CUDA 12.04 版本有额外的条件编译逻辑，对应不同的线程块尺寸（32x32 vs 64x64）
