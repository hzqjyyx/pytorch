- **文件类型**：自动生成的CUDA核函数文件（由 `generate_kernels.py` 生成）

- **主要功能**：实现高效attention机制的前向传播CUDA核函数，专门针对半精度浮点数（float16）和未对齐的数据访问

- **核函数特征**：
  - 定义了6个全局核函数，支持不同的GPU架构（SM50/SM70/SM75）
  - 使用CUTLASS库实现优化的矩阵运算
  - 参数配置包括：
    - `64x64x64` 配置：针对较小的特征维度
    - `32x128x128` 寄存器文件（RF）配置：平衡寄存器和性能
    - `32x128x65536` 全局内存（GMEM）配置：处理更大的问题规模

- **架构支持**：
  - SM50（Maxwell）：sm50-sm70
  - SM70（Volta）：sm70-sm75
  - SM75（Turing）：sm75-sm80

- **核函数工作流**：
  1. 检查CUDA架构兼容性
  2. 通过 `advance_to_block()` 处理块级任务分配
  3. 调用模板化的 `attention_kernel()` 执行实际计算
  4. 不兼容架构时输出错误提示

- **优化特点**：
  - 使用 `__launch_bounds__` 指定线程数和最小块数，优化占用率
  - 条件编译确保运行时架构匹配
  - `false` 参数表示未启用特定的对齐优化
