# TriangularOpsUtils.h 文件分析

## 主要功能

这是一个为三角矩阵操作（Triu/Tril）提供工具函数的头文件。

### 包含的工具函数

- **`batchCountTrilTriu()`** (第10-18行)
  - 计算批量矩阵的批次数量
  - 忽略步长为0的维度
  - 遍历除最后两个维度外的所有维度，累乘非零步长维度的大小

- **`checkTrilTriuBatchContiguous()`** (第24-55行)
  - 检查张量是否满足三角操作的必要性质
  - 优先返回完全连续的张量
  - 对于大于4维的张量，检查批次连续性
  - 如果张量不满足条件，返回重新步长化后的版本
  - 支持 `allow_zero_stride` 参数处理特殊情况

## 核心特点

- 处理任意批次维度的矩阵
- 特殊处理步长为0的维度（广播维度）
- 为3维以下张量提供优化路径
- 维护内存连续性以提升性能

## 简明总结

- **目的**: 为 Triu（上三角）和 Tril（下三角）操作提供批量处理和内存布局检查
- **关键方法**: 批次计数、连续性检查、自动步长优化
- **使用场景**: 批量三角矩阵操作的预处理
