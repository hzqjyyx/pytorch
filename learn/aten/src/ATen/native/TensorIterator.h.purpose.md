- **张量迭代的统一接口**：为元素级操作（算术、比较、三角函数等）提供的辅助类，通过标准化的迭代模式来处理多个张量的协同操作

- **自动广播与类型转换**：自动处理输入张量的广播和类型转换，支持 NumPy 风格的数组迭代 API

- **配置构造器模式**：通过 `TensorIteratorConfig` 灵活配置输入/输出张量（输出必须先添加），支持拥有/借用引用两种内存管理方式

- **形状与步长优化**：计算和重排维度以提高计算效率，通过 `coalesce_dimensions()` 合并相邻维度，减少显式迭代的维度数

- **通用数据类型处理**：自动推导"通用 dtype"用于计算，支持类型提升规则；支持对输入/输出进行独立的类型转换和转换

- **多设备支持**：支持 CPU/GPU（CUDA）设备，可通过 `with_32bit_indexing()` 将大张量分割成多个 32 位可寻址的子迭代器

- **灵活的内核驱动机制**：提供 `for_each()`/`parallel_reduce()` 等方法驱动用户定义的内核，支持 CPU 和 GPU 异构计算

- **归约操作支持**：标记内置的归约操作并管理累积状态（`should_accumulate()` 和 `is_final_output()`）

- **输出分配与调整**：自动分配或调整输出张量的大小和步长，支持就地操作、函数式调用和显式输出三种模式

- **操作数元数据管理**：通过 `OperandInfo` 结构体管理每个张量的数据指针、步长、设备、数据类型等属性
