# FractionalMaxPooling.h 文件分析

**主要功能：**

- **generate_intervals 模板函数** - 为分数最大池化生成采样间隔序列。根据输入大小、输出大小和池化核大小，计算每个输出位置应该采样的输入区间起始位置。使用随机样本参数实现随机性。

- **fractional_max_pool_check_shape 模板函数** - 验证分数最大池化操作的输入张量形状和类型。检查随机样本张量是否与输入张量维度匹配、数据类型一致，以及各维度大小是否满足要求（支持2D和3D池化）。

**核心内容：**

- `generate_intervals()` 通过线性插值计算池化窗口位置
- 支持2D和3D分数最大池化（`ndim=2` 或 `ndim=3`）
- 处理有/无batch维度的情况
- 包含详细的张量形状和类型验证
