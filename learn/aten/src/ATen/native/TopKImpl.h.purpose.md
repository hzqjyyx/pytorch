**TopKImpl.h 主要功能分析**

这个文件实现了 PyTorch 的 TopK 操作的核心算法循环。

**核心函数：`topk_impl_loop`**

- 接收要处理的张量数据指针、步长、k值、维度大小等参数
- 处理 k=0 的特殊情况（直接返回空结果）

**算法流程**

- 为每个样本构建包含 `(值, 原始索引)` 对的队列
- 根据 k 值相对于维度大小的比例选择不同策略：
  - **k * 64 <= dim_size**：使用 `std::partial_sort`（更高效）
  - **否则**：使用 `std::nth_element` + 可选的 `std::sort`

**排序逻辑**

- 支持 `largest` 参数控制升序/降序
- 支持 `sorted` 参数控制是否对 top-k 结果进行排序
- 特殊处理 NaN 值，使其在排序时始终排在前面（NumPy 兼容性）

**输出**

- 将排序后的值写入 `mode_values`
- 将对应的原始索引写入 `mode_indices`

**设计特点**

- 使用模板支持不同数据类型和累加器类型
- 通过命名空间支持 CPU 功能扩展（如特殊指令集）
- 处理多维张量的步长访问
