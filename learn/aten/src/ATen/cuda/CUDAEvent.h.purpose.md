# CUDAEvent 类主要功能分析

这是一个 CUDA 事件（Event）的 C++ 包装类，用于管理和同步 GPU 操作。主要特点：

## 核心设计
- **Move-only 语义**：支持移动构造/赋值，禁止拷贝（第 57-66 行）
- **懒加载创建**：事件在首次记录时才真正创建，不在构造时创建（第 114-116 行）
- **设备绑定**：每个事件绑定到特定的 CUDA 设备（第 22-26 行注释）

## 主要功能

- **事件创建与销毁**
  - 通过 flags 参数自定义事件行为（默认 `cudaEventDisableTiming`）
  - 支持从 IPC 句柄重构事件用于进程间通信（第 34-40 行）
  - 析构时自动清理资源（第 44-55 行）

- **事件记录**
  - `record()`：在指定流上记录事件
  - `recordOnce()`：只记录一次（第 108-110 行）
  - 自动验证事件和流的设备匹配（第 118-119 行）

- **流同步**
  - `block()`：使流等待事件完成（第 134-146 行）
  - `synchronize()`：主机线程等待事件完成（第 163-171 行）

- **查询与测量**
  - `query()`：非阻塞查询事件是否完成（第 88-104 行）
  - `elapsed_time()`：计算两个事件间的耗时（毫秒，第 149-160 行）

- **IPC 支持**
  - `ipc_handle()`：获取事件的 IPC 句柄用于跨进程共享（第 174-182 行）

- **GPU 追踪集成**
  - 通过 `GPUTrace` 接口记录事件的创建、记录、等待、同步操作（第 48-50, 122-127 等行）

## 关键特性

- **无缝转换**：支持隐式转换为 `cudaEvent_t`（第 68 行）
- **集合友好**：重载 `<` 运算符支持在 set 中使用（第 71-73 行）
- **异常安全**：析构时捕获所有异常防止程序崩溃（第 54 行）

**要点总结：**
- 管理 CUDA 事件的生命周期和状态
- 提供主机-设备、设备-设备间的同步机制
- 支持 GPU 时间测量和性能分析
- 支持跨进程事件共享（IPC）
- 集成 GPU 操作追踪用于调试和性能监控
