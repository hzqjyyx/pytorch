- **文件用途**：提供从内存指针获取对应 CUDA 设备信息的功能
- **核心函数**：`getDeviceFromPtr(void* ptr)` - 接收一个指针，返回该指针所在的设备信息
- **实现原理**：
  - 调用 `cudaPointerGetAttributes()` 获取指针的属性结构
  - 检查指针类型是否为已注册的 CUDA 内存（非主机内存）
  - 从属性结构中提取设备索引
  - 返回包含设备类型和索引的 `Device` 对象
- **主要检查**：确保传入的指针不是未注册的主机内存，否则抛出错误
- **应用场景**：在需要确定某个内存地址属于哪个 GPU 设备时使用
