## TensorInfo.cuh 文件分析

这个文件定义了 CUDA 内核中使用的张量元数据结构和索引计算工具。

### 核心组件

**TensorInfo 结构体** (lines 10-36)
- 模板类，用于在 CUDA 内核中传递张量信息
- 存储张量数据指针、维度数、每维的大小和步长
- 最多支持 25 个维度（`MAX_TENSORINFO_DIMS`）
- `isContiguous()` 方法：检查张量是否为连续存储

**关键方法** (lines 21-24)
- `reduceDim(int dim)`：将指定维度的大小设为 1（用于模拟归约维度）
- `collapseDims(const int excludeDim)`：合并连续维度以优化计算

**IndexToOffset 索引转换** (lines 76-114)
- 两个特化版本：
  - **静态维度版本** (Dims > 0)：编译时已知维度数，性能更优
  - **动态维度版本** (Dims = -1)：运行时维度数，灵活性更高
- 将线性索引转换为多维张量中的内存偏移量
- 算法：从最高维开始，逐维计算索引和对应的内存偏移

### 核心功能列表

- **张量元数据管理**：CUDA 内核参数化的张量布局信息
- **连续性检查**：判断张量是否为连续内存
- **维度优化**：支持合并多个维度以减少计算复杂度
- **索引计算**：高效地从线性ID转换为多维张量偏移
- **编译优化**：提供静态和动态两种索引转换实现
