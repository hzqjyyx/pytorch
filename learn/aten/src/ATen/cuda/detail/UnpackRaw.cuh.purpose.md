**主要功能分析：**

- **PhiloxCudaState 解包工具** - 提供设备端函数来从 PhiloxCudaState 实例中提取伪随机数生成器的种子(seed)和偏移量(offset)

- **CUDA 图捕获支持** - `unpack()` 函数处理两种情况：
  - 图捕获模式：从指针读取动态种子和偏移量
  - 非图捕获模式：直接返回存储的值

- **内联设计** - 使用 `__forceinline__` 确保函数在消费端内核中被直接编译，避免函数调用开销

- **主机设备双端兼容** - `__host__ __device__` 修饰符允许在主机和设备代码中都能使用

- **JIT 代码生成友好** - 独立文件设计便于 JIT 编译器复制原始定义到生成的代码中

- **cuDNN 支持** - 提供 `unpack_cudnn` 全局函数和包装器用于 cuDNN 库的种子/偏移量提取

- **避免模板污染** - 不使用 `#pragma once`，允许多次包含以支持代码生成流程
