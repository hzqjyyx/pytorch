## IntegerDivider.cuh 主要功能解析

这个文件实现了一个 **快速整数除法工具类**，通过乘法和位移操作替代传统除法运算来提高性能。

### 核心原理

基于数学技巧：对于任意正整数除数 `d`，可以找到"魔数" `m` 和移位量 `s`，使得：
```
⌊n / d⌋ = ⌊(m * n) / 2^(32+s)⌋
```

这样可以用一次乘法和一次位移替代昂贵的除法操作。

### 实现细节

- **通用模板** (`IntDivider<Value>`): 对于大多数类型，直接使用常规除法 (`n / divisor`)
- **特化版本** (`IntDivider<unsigned int>`): 针对 32 位无符号整数的快速实现
  - 构造时计算魔数 `m1` 和移位量 `shift`
  - `div()` 方法：利用 CUDA 的 `__umulhi()` 指令获取乘法结果的高 32 位，然后位移
  - `mod()` 方法：通过 `n - div(n) * divisor` 计算余数
  - `divmod()` 方法：同时返回商和余数

### 关键限制

- 仅对无符号整数优化
- 假设被除数 ≤ INT32_MAX
- 魔数计算需要 64 位整数算术

### 主要功能

- **DivMod 结构体**: 封装除法和模运算结果
- **三个操作接口**: `div()`、`mod()`、`divmod()`
- **主机和设备代码**: 使用 `C10_HOST_DEVICE` 宏支持 CPU 和 GPU 执行
