## NNAPI Model Loader 功能分析

### 核心目的
这两个文件实现了 PyTorch ATen 库中 NNAPI (Android Neural Networks API) 模型的加载和初始化功能。

### 主要数据结构

**SerializedModel** (序列化模型格式)
- 包含版本号、操作数数量、值数量、操作数量、输入输出数量等元数据
- 后续跟随：操作数定义、值数据、操作参数、输入输出索引

**SerializedOperand** (操作数)
- 类型、维度数量、缩放因子、零点值
- 用于描述张量的属性

**SerializedValue** (值)
- 索引、数据来源类型、数据长度
- 支持三种来源：立即数、缓冲区编号、内存编号

**SerializedOperation** (操作)
- 操作类型、输入输出数量
- 定义 NNAPI 执行的具体操作

### 关键函数

**load_nnapi_model()**
- 参数：NNAPI wrapper、模型指针、序列化数据、缓冲区信息等
- 工作流程：
  1. 验证序列化数据的大小和完整性
  2. 解析模型元数据
  3. 逐个添加操作数到 NNAPI 模型
  4. 处理值数据（从缓冲区或立即数读取）
  5. 添加操作到模型
  6. 标识模型的输入输出

**value_physical_size()**
- 计算值的物理存储大小（4 字节对齐）

### 核心特性

- **内存安全检查**：多层边界验证，防止缓冲区溢出
- **灵活的数据来源**：支持立即数、外部缓冲区、GPU 内存
- **NNAPI 集成**：直接调用 NNAPI wrapper 接口构建计算图
- **版本控制**：支持序列化格式版本管理

### 主要处理流程

```
验证模型大小 → 解析元数据 → 添加操作数 → 设置值数据 → 
添加操作 → 标识输入输出 → 返回消耗字节数
```

### 关键点

- **Bullet Points**:
  - 将序列化的 NNAPI 模型二进制数据解析并加载到 ANeuralNetworksModel 对象
  - 支持从三种来源获取操作数值：立即数、编号缓冲区、编号内存
  - 严格的边界检查和整数溢出防护
  - 返回实际消耗的字节数和模型的输入输出数量
  - 适配 Android NNAPI 计算图构建的标准流程
