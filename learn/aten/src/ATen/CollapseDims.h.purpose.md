# CollapseDims.h 功能分析

这个文件实现了一个模板函数 `collapse_dims`，用于优化张量的维度表示。

## 核心功能

**目的**：将张量的多个维度"折叠"成更少的维度，同时保持元素的内存顺序不变。

**工作原理**：
- 扫描张量的 sizes 和 strides 数组
- 移除 size 为 1 的维度
- 合并相邻的可连续访问的维度（当 `stride[i] == size[i+1] * stride[i+1]` 时）
- 可选地保留一个指定的维度（excludeDim 参数）

**返回值**：
- 保留维度在新数组中的索引（如果指定了 excludeDim）
- 折叠后的新维度数

## 关键特性

- **模板化**：支持任意数值类型的 sizes/strides 数组
- **原地修改**：直接修改传入的 sizes 和 strides 指针
- **边界情况处理**：
  - 所有维度 size 为 1 时，返回单个 size=1 的维度
  - excludeDim 参数验证范围在 [-1, dims)

## 应用场景

- 内存布局优化
- 减少张量操作的维度复杂度
- 提高缓存效率
