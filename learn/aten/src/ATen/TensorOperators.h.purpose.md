# TensorOperators.h 文件分析

这个文件定义了 ATen 张量的二元操作符重载。主要通过宏展开来实现。

## 核心机制

**AT_FORALL_BINARY_OPS 宏** (第14-34行)：
- 列举所有支持的二元操作符：`+`, `*`, `-`, `/`, `%`, `&`, `|`, `^`, `<`, `<=`, `>`, `>=`, `==`, `!=`
- 对每个操作符定义三种形式的实现

**DEFINE_OPERATOR 宏** (第36-45行)：
- 为每个操作符生成三个重载函数：
  1. `Tensor op Tensor` - 两个张量操作
  2. `Tensor op Scalar` - 张量与标量操作
  3. `Scalar op Tensor` - 标量与张量操作（使用反向实现）

## 特殊处理

- **加法/乘法/位运算**：交换律操作，正向和反向实现相同
- **减法/除法/取模**：非交换律操作，反向操作需要创建临时张量并填充标量值
  - 例如：`Scalar - Tensor` 转换为 `empty_like(y).fill_(x).sub_(y)`

## 功能总结

- 为张量提供直观的操作符语法（如 `a + b`、`a * 2`）
- 支持张量-张量、张量-标量、标量-张量三种组合
- 通过宏展开避免代码重复
- 条件编译支持按操作符头文件包含模式
